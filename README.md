# ARSH Hospital — Next.js

Next.js App Router project converted from the supplied HTML pages. The source HTML is kept in `arshhopital frtonendhtml waale/` for reference. Page markup, custom CSS, metadata and existing interactions are carried into the Next.js routes.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` — Homepage
- `/blog` and `/blog-detail`
- `/doctors`
- `/news-media`
- `/book-appointment`
- `/facilities` and `/angiography`
- `/international-patients`
- `/patient-stories`
- `/specialities` and `/orthopedic-doctor-in-gaya-bihar`

Bootstrap 5.3.8, Bootstrap Icons and the source Google Fonts are included once in the root layout. The original page-specific CSS and JavaScript remain separated by page under `content/` and `public/page-scripts/`.
